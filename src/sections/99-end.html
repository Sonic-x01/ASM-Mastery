Registers (x64)

  • rax eax ax ah al64 · 32 · 16 · 8
  • r8 r8d r8w r8br8–r15: مفيش high byte
  • كتابة eax بتصفّر الـ 32 العلياax/al لأ
  • rip · rsp · rflagsIP · stack · flags
  • SysV callee-saved: rbx rbp r12–r15
  • Win64 callee-saved: + rdi rsi xmm6–15

Calling conventions

  • SysV: rdi rsi rdx rcx r8 r9floats xmm0–7 · al = #xmm
  • Win64: rcx rdx r8 r9 + 32B shadowبالمكان مش بالنوع
  • return rax (+rdx) · xmm0
  • rsp % 16 == 0 قبل الـ callوإلا movaps crash
  • cdecl add esp, N · stdcall ret N32-bit
  • fastcall ecx, edx · thiscall this = ecx32-bit

Flags والـ jumps

  • cmp a, b = sub من غير تخزينtest = and
  • unsigned: ja jae jb jbeCF, ZF
  • signed: jg jge jl jleSF, OF, ZF
  • je/jz ZF=1 · js SF=1 · jo OF=1
  • inc/dec مبيلمسوش CFفخ
  • floats (comisd) ← ja/jb + jp للـ NaN

Addressing وأحجام

  • [base + index*scale + disp]scale 1/2/4/8
  • byte word dword qword1 2 4 8
  • lea = حساب من غير ذاكرة×3 ×5 ×9، pointers
  • [rip+x] = global في x6432-bit: عنوان مطلق
  • movzx unsigned · movsx/movsxd/cdqe signedنوع المتغير!
  • little-endian: 0x11223344 = 44 33 22 11

Stack والـ frames

  • push = rsp−=8; [rsp]=xpop العكس
  • call = push next + jmp · ret = pop rip
  • prologue push rbp / mov rbp, rsp / sub rsp, N
  • locals [rbp−x] · ret [rbp+8]x64
  • 32-bit: arg1 [ebp+8]، arg2 [ebp+0Ch]
  • red zone (SysV): 128B تحت rspمش في Windows

Windows internals

  • PEB: gs:[60h] · fs:[30h]x64 · x86

  • Export dir: Names +20h · Ordinals +24h · Funcs +1Ch

PE offsets

  • MZ · e_lfanew [3Ch] · PE\0\0

  • section header 40B: VSize +8, VA +12, RawSize +16, Raw +20, Flags +36
