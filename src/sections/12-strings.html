الـ String Instructions: نسخ وملء وبحث ومقارنة

x86 فيه instructions مخصوصة للتعامل مع blocks من الذاكرة: بتشتغل على [rsi] و[rdi] وبتحرك الـ pointers لوحدها، ومع rep بتلف rcx مرة. هتشوفها في memcpy/memset اللي الـ compiler بيحطهم inline، في الكود القديم، وكتير جدًا في الـ shellcode والـ unpackers لأنها صغيرة.

العيلة كلها b · w · d · q

Instructionبتعمل (مرة واحدة)مع repالمقابل في C
movsb/w/d/q[rdi] ← [rsi]؛ rsi وrdi += حجمrep: rcx مرةmemcpy
stosb/w/d/q[rdi] ← al/ax/eax/rax؛ rdi += حجمrepmemset
lodsb/w/d/qal/… ← [rsi]؛ rsi += حجمنادر مع repقراية byte ورا byte (loops الـ decoders)
scasb/w/d/qcmp al, [rdi]؛ rdi += حجمrepne: لحد ما يلاقيstrlen / memchr
cmpsb/w/d/qcmp [rsi], [rdi]؛ الاتنين += حجمrepe: طول ما متساويينmemcmp

الحجم بييجي من آخر حرف (b=1، w=2، d=4، q=8)، والاتجاه من DF: cld (DF=0) = لقدّام وده الطبيعي (الـ ABI بيضمنه عند أي call)، وstd = لورا. وrep بتفحص rcx قبل كل لفة: لو rcx = 0 من الأول مفيش ولا لفة.

التلاتة الأساسيين في المعمل memset · memcpy · strlen

section .data src: db "malware.exe", 0 dst: times 16 db 0xEE section .text demo: ; memset(dst, 0, 16) lea rdi, [rel dst] xor eax, eax mov ecx, 16 rep stosb ; 16 x [rdi++] = al ; memcpy(dst, src, 12) lea rsi, [rel src] lea rdi, [rel dst] mov ecx, 12 rep movsb ; 12 x [rdi++] = [rsi++] ; strlen(src) the "old school" way lea rdi, [rel src] xor eax, eax ; al = 0 : the byte we search for mov rcx, -1 ; "infinite" counter repne scasb ; scan until [rdi] == 0 not rcx ; rcx = length + 1 dec rcx ; rcx = strlen = 11 mov rax, rcx ret
🔬
حيلة repne scasb لحساب الطول

or rcx, -1 (أو mov rcx, -1) + repne scasb + not rcx + dec rcx = strlen. الـ compilers القديمة (والـ shellcode وكود Delphi) بيستخدموها كتير. لو شفت الـ 4 سطور دول في sample — مش محتاج تحللهم، دي strlen. وبالـ w (repne scasw) = wcslen للـ wide strings.

الـ 0xCC في الـ Debug builds

MSVC مع /RTC (الافتراضي في Debug) بيملا الـ locals بـ 0xCC بـ rep stosd وeax = 0xCCCCCCCC في أول كل دالة — عشان أي استخدام لمتغير من غير قيمة يبان. لو شفت ده في sample = اتعمله compile كـ Debug (هدية: غالبًا فيه symbols ومسارات PDB).

🧬

في الـ shellcode والـ unpackers

rep movsb = انسخ الـ payload لمكان جديد. lodsb + xor al, key + stosb = decoder كلاسيكي بيقرا byte ويفكه ويكتبه. وشكل lodsb + ror + add = حساب hash لاسم API.

Wide strings (UTF-16) Windows

على Windows أغلب الـ strings الداخلية UTF-16 (2 bytes للحرف). الـ loops عليها بتستخدم word و scale 2: movzx eax, word ptr [rcx+rdx*2]، وlodsw/stosw/scasw. ومقارنات أسماء الـ DLLs في الـ PEB (هنشوفها) بتبقى على UTF-16 — وكتير بتتعمل case-insensitive بـ or ax, 20h.

default rel section .data wname: dw 'K','E','R','N','E','L','3','2','.','D','L','L', 0 ; UTF-16 string section .text global _start _start: ; length of a wide string with lodsw lea rsi, [wname] xor ecx, ecx .count: lodsw ; ax = [rsi], rsi += 2 test ax, ax jz .done inc ecx jmp .count .done: mov edi, ecx call print_int ; 12 characters call print_nl ; print it lowercase: or every letter with 0x20 lea rsi, [wname] .print: lodsw test ax, ax jz .end cmp al, 'A' jb .out cmp al, 'Z' ja .out or al, 0x20 ; to lower case .out: movzx edi, al call print_char jmp .print .end: call print_nl xor edi, edi call exit

rep stosq مع rcx = 4 وrax = 0. بتصفّر كام byte؟ 4 8 32 64 4 مرات × 8 bytes (q = qword) = 32 byte. الـ q = 8 bytes في كل مرة. movsb (من غير rep) مع DF = 0 بتعمل إيه في الـ registers؟ rsi += 1، rdi += 1 rsi −= 1، rdi −= 1 rcx −= 1 بس مبتغيرش registers بتنسخ byte وتحرك الـ pointer-ين لقدّام. rcx بيتغير بس مع rep. DF = 0 = لقدّام. repe cmpsb بتقف إمتى؟ لما تلاقي byte متساوي بعد rcx مرة بالظبط دايمًا لما rsi = rdi لما تلاقي اختلاف (ZF = 0) أو rcx يوصل 0 — أيهما الأول repe = "كرر طول ما متساويين". بعدها jne = لقينا اختلاف (memcmp ≠ 0). e = equal: الـ rep بتكمّل طول ما الشرط ده متحقق. لقيت في sample: lodsb ثم xor al, 5Ah ثم stosb ثم loop لنفس المكان، وrsi = rdi في الأول. ده: نسخ string XOR decoder بيفك buffer في مكانه بمفتاح 0x5A (rcx byte) strlen مقارنة اقرا byte → فكه → اكتبه في نفس المكان → كرر. حط breakpoint بعد الـ loop وشوف الـ plaintext. lods = اقرا، xor = غيّر، stos = اكتب. في أول دالة MSVC لقيت mov eax, 0CCCCCCCCh وrep stosd. ده: تشفير anti-debugging Debug build بيملا الـ locals بـ 0xCC (/RTC) breakpoints ميزة debug في MSVC. الـ release builds مفيهاش ده. (ولاحظ: 0xCC = int3، فلو حد نفذ ذاكرة متملية بيها هيوقف على طول.) ده سلوك compiler في نوع معيّن من الـ builds. movzx eax, word ptr [rcx+rax*2] جوه loop. ده بيقرا: حرف من wide string (UTF-16) byte من buffer pointer dword word + scale 2 = عناصر 2 bytes = wchar_t على Windows. الحجم word والـ scale 2… حوّل الـ string msg لـ uppercase في مكانها باستخدام lodsb وstosb (rsi = rdi = بداية الـ string)، واطبعها. الحروف الصغيرة بس اللي تتغير (and al, 0DFh أو sub al, 32). المطلوب:
CONNECT TO 10.0.0.5:4444 default rel section .data msg: db "connect to 10.0.0.5:4444", 0 section .text global _start _start: lea rsi, [msg] lea rdi, [msg] ; loop: lodsb / if 'a'..'z' make it upper / stosb / stop after the 0 lea rdi, [msg] call print_str call print_nl xor edi, edi call exit CONNECT TO 10.0.0.5:4444 default rel section .data msg: db "connect to 10.0.0.5:4444", 0 section .text global _start _start: lea rsi, [msg] lea rdi, [msg] .next: lodsb ; al = *rsi++ cmp al, 'a' jb .store cmp al, 'z' ja .store and al, 0xDF ; clear bit 5 -> upper case .store: stosb ; *rdi++ = al test al, al jnz .next lea rdi, [msg] call print_str call print_nl xor edi, edi call exit rdi وrsi = pointers لـ buffers، rdx = الطول. رجّع rax = 1 لو متطابقين تمامًا، و0 لو لأ. استخدم repe cmpsb (افتكر: لو الطول صفر، يعتبروا متطابقين). equal: xor eax, eax ret equal: mov rcx, rdx xor eax, eax test rcx, rcx jz .same ; length 0 -> equal repe cmpsb ; compare while equal and rcx != 0 jne .diff ; stopped on a difference .same: mov eax, 1 .diff: ret rdi = string منتهية بصفر. اعكسها في مكانها ("abc" ← "cba"). احسب الطول الأول، وبعدين بدّل الأطراف لحد ما يتقابلوا. reverse: ret reverse: mov rsi, rdi ; rsi = left mov rdx, rdi .find_end: cmp byte [rdx], 0 je .found inc rdx jmp .find_end .found: dec rdx ; rdx = right (last char) .swap: cmp rsi, rdx jae .done mov al, [rsi] mov cl, [rdx] mov [rsi], cl mov [rdx], al inc rsi dec rdx jmp .swap .done: ret اسم الدالة المعروفة اللي الكود ده بيعملها؟ (بترجع في rax) func: xor eax, eax or rcx, -1 repne scasb not rcx lea rax, [rcx-1] ret بتدوّر على byte = al = 0، وبتعد… دي strlen(rdi) بالـ idiom القديم: بتدوّر على الـ NUL، وnot rcx − 1 = عدد الحروف. نسخة lea rax, [rcx-1] بتطرح من غير ما تغيّر rcx.
