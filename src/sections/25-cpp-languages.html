C++ في الـ binary، ولمحة عن Go وRust و.NET

كتير من الـ malware الحديث مكتوب بـ C++ (RATs، ransomware) أو Go/Rust (cross-platform، صعب التحليل). كل لغة ليها «بصمة» في الـ assembly: إزاي بتنادي الـ methods، إزاي بتخزن الـ strings، وفين بتسيب أسماء ممكن ترجّعها. لو عرفت البصمة، الـ binary الغريب بيبقى مألوف.

🧵

std::string

MSVC (32 bytes): +0 buffer 16 byte أو pointer لو أطول من 15 حرف (SSO)، +16 size، +24 capacity — لو capacity ≥ 16 ← الـ data في الـ heap. libstdc++: +0 pointer، +8 size، +16 buffer محلي. هتشوف cmp qword [rcx+18h], 0Fh قبل كل قراية = «فين الـ data؟».

📚

std::vector وexceptions

vector = 3 pointers: begin، end، end_of_storage؛ الحجم = (end − begin) / sizeof(T) ← هتشوف sub + sar. الـ exceptions: _CxxThrowException (MSVC) / __cxa_throw (gcc)، والـ catch blocks بتبان «مفصولة» عن الـ graph.
