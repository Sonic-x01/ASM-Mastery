hexdump -C بـ Assembly خالص

متوسط▼

برنامج NASM من غير libc بيقرا stdin ويطبعه بشكل hexdump -C بالظبط. بيجمع: syscalls (13)، loops وعناوين (4، 9)، تحويل أرقام لـ hex (8)، والـ buffers (12).

read/write syscallshex conversionbufferscallee-saved regs
  1. اقرا stdin في buffer في .bss (لحد 4096 byte) — في loop لحد EOF: read ممكن ترجّع أقل من المطلوب (سطر واحد من الـ terminal أو chunk من pipe)، والرجوع بـ 0 = EOF.
  2. put_hex: دالة بتكتب N hex digits لرقم في buffer (من الآخر للأول بـ and 15 + جدول "0123456789abcdef").
  3. السطر: offset (8 digits) + مسافتين + 16 byte (مسافة زيادة بعد التامن) + |ascii| — ابنيه في buffer واعمله write واحدة.
  4. السطر الناقص: 3 مسافات مكان كل byte ناقص عشان الـ ASCII يفضل في مكانه، وفي الآخر اطبع الطول الكلي.
  5. Stretch: ملفات أكبر من 4KB (اطبع وفضّي الـ buffer كل ما يتملي)، وضغط السطور المكررة بـ * زي الأداة الأصلية.

API Hash Resolver (HashDB مصغّر)

متوسط▼

لقيت في sample ثوابت زي 0xEC0E4E8E و0x382C0F97. اعمل أداة بتحسب hashes لأسماء APIs بالخوارزميات الشهيرة وتطابق الثوابت المجهولة — نفس فكرة HashDB (المرحلة 8 و22).

ROR13djb2FNV-1a32-bit arithmetic
  1. اكتب الـ 3 خوارزميات (uint32_t عشان الـ overflow يبقى زي الـ asm بالظبط).
  2. جدول أسماء APIs (الأشهر في الـ loaders) وجدول ثوابت «لقيتها في الـ sample».
  3. لكل ثابت: جرّب كل خوارزمية على كل اسم واطبع التطابق.
  4. Stretch: اقرا الأسماء من export table حقيقي (من مشروع 03)، وزوّد CRC32 وROR13 بتاع الـ module + function (Cobalt Strike style).

PE Parser من الصفر

متقدم▼

أداة triage بتطبع الـ headers والـ sections (بالصلاحيات) والـ imports لأي PE64 — شغالة هنا على نفس الـ EXE الحقيقي بتاع الـ PE Explorer (المرحلة 20)، متخزن جوه البرنامج كـ array.

struct offsetsRVA → offsetimport descriptorsbounds checks
  1. اتأكد من MZ وPE\0\0، واقرا Machine وNumberOfSections وEntryPoint وImageBase.
  2. اطبع الـ section table: الاسم، VA، VSize، Raw، RawSize، والصلاحيات RWX — وعلّم [!] على أي RWX أو RawSize = 0.
  3. rva2off() بالـ section table، وامشي على الـ import descriptors: اسم كل DLL وأسماء الدوال (hint/name).
  4. كل قراية لازم bounds check — الـ malware بيعمل headers بايظة عمدًا عشان يكسر الأدوات (ومحلّلك هو اللي لازم ميقعش).
  5. Stretch: اقرا من ملف (argv[1])، entropy لكل section، والـ exports وTLS callbacks.
